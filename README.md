# Sukuu ERP comprehensive website update

Production-ready static website package for `https://sukuux.com/`, prepared for a GitHub-first deployment.

## What is included

- Responsive, mobile-first homepage with progressive animation
- Two touch, keyboard and autoplay-enabled school-environment slideshows
- Six presentation-led capability clusters expressing 24 connected capabilities
- Official Sukuu ERP logo in the navigation and footer
- Ghanaian private basic-school imagery spanning lower-primary to junior-high learners
- Outcome-led academic, finance, operations, family and leadership narratives
- Sukuu product ecosystem and Intelligence Bridge authority boundary
- AYIVI Systems Limited corporate profile and services
- Dedicated call, WhatsApp, email and demonstration conversion paths
- Search metadata, JSON-LD, sitemap, robots, social card and web manifest
- GitHub Pages deployment workflow and custom-domain file
- Standalone single-file edition for direct review or simple hosting

## Quick review

Open `index-standalone.html` directly in a modern browser. It contains the page styles, interactions, official logo and six school-environment images in one file.

## Repository deployment

1. Create or select the GitHub repository for the website.
2. Copy all files and folders in this package into the repository root.
3. Commit and push to the `main` branch.
4. In GitHub, open **Settings → Pages** and select **GitHub Actions** as the source.
5. Confirm the custom domain is `sukuux.com` and enforce HTTPS after DNS validation.

Read `GITHUB-DEPLOYMENT.md` and `SEO-LAUNCH-CHECKLIST.md` before changing live DNS or replacing the current site.

## Content authority

The client presentation is the public content authority. The website communicates 24 connected capabilities only through its six approved, outcome-led clusters; internal module names and implementation details are not published. See `CONTENT-GOVERNANCE.md`.
